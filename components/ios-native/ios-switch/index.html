iOS 开关（ios-switch）

iOS 系统开关：51×31 轨（关灰 / 开系统绿）+ 27px 白 knob 带阴影，knob 位移走 spring、轨色变化走阻尼。demo 是三行设置上下文，点击开关切换。

点开关切换：knob 走 --ios-spring 轻回弹位移 20px，轨色走 --ios-damped 阻尼过渡。

组件要点

  • 51×31 轨：关 #E9E9EA / 开 --ios-green（系统绿，平台正确），颜色过渡 --ios-damped。
  • 27px 白 knob：带阴影，开态位移 20px，位移过渡 --ios-spring 轻回弹——位移回弹、颜色不回弹。
  • 状态一眼可读：只有位置 + 底色，不加文字、不加勾选图标、不加描边。
  • demo 里三行设置是内联最小 markup，不 link 任何其它组件的 CSS。

动手点

  • 点开关：knob 回弹位移与轨色变绿同时发生，两条曲线各走各的。
  • 连续开→关→开：transition 始终追最终状态，不会半途卡住。

刻意没做

  • 无 stock 蓝、无描边、无发光——开态只有系统绿。
  • 无 backdrop-filter、无毛玻璃。
  • 行本身不可点：交互只挂在开关上（与源 demo 一致）。
