组件要点

  • HIG 大标题体系：34/41 700 大标题 + 15pt --ios-ink2 副标题，下面直接进入内容流。
  • 全栏实心：状态栏与导航栏都是不透明 --ios-bg，只用 .5px 发丝线 --ios-sep 收边——整段 0 个 backdrop-filter。
  • 居中 17/600 标题：「拾光」居中，左侧 chevron+「书架」、右侧「编辑」共用唯一强调色 --ios-accent。
  • 触控尺寸：两侧动作区 min-width 64px，满足 ≥44pt。

动手点

  • 向下滚动，看大标题稳稳待在内容流顶部（基线画法：不吸顶、不折叠）。
  • 数一数栏与栏之间的边界：只有发丝线，没有阴影、没有模糊。

刻意没做

  • 无 backdrop-filter、无毛玻璃导航——非玻璃时代的 iOS 正确画法。
  • 无 stock 蓝一色到底：彩色文字只有赤陶 --ios-accent。
  • 大标题不做滚动折叠联动（collapse），保持静态 HIG 基线。
