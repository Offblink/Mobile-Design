组件要点

  • inset grouped：13pt 分组小标题（--ios-ink2，非 ALL-CAPS）+ 白卡圆角 16 + 微投影，卡片四周不贴屏幕边。
  • 行结构：30px 圆角 8 彩色图标方块 + 17px 行名 + 16px --ios-ink2 值 + 8×14 chevron，行高 ≥52pt。
  • 57px 内嵌分隔线：分隔线从图标之后（左起 57px）起，不是通栏线；.5px 发丝线 --ios-sep。
  • 按压反馈：:active 底色 5% 墨色，过渡走 --ios-damped。

动手点

  • 按住任意一行：看按压底色从行内浮现。
  • 点「睡前提醒」行内的开关占位（本组件内联的最小开关 markup）。

刻意没做

  • 无 ALL-CAPS 分组标题、无 stock 蓝、无通栏分隔线。
  • 无 backdrop-filter、无毛玻璃卡片。
  • 分隔线绝不穿过图标——57px 内嵌是硬规则。
