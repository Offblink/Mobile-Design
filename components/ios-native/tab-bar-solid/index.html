组件要点

  • 84pt 实心底：rgba(251,247,239,.98) 近乎全不透明的暖白 + 顶部 .5px 发丝线 --ios-sep 收边。
  • 4 个 26px SVG tab：active --ios-accent、未选 #9A938A，10px 标签字重 500。
  • 只有颜色在动：hover 与点击都走 --ios-damped 阻尼——颜色不回弹，图标不缩放。
  • 0 个 backdrop-filter 是刻意的：非玻璃时代用「实心 + 发丝线」，不是毛玻璃。

动手点

  • 点四个 tab 切换：观察只有颜色过渡，没有胶囊底、没有弹跳。
  • hover 未选中的 tab，同样是一条阻尼色彩过渡。

刻意没做

  • 无 backdrop-filter / 毛玻璃 Tab 栏——这条是刻意的，见上。
  • 无 stock 蓝、无选中胶囊底、无 badge 红点。
  • active 不加缩放/回弹：HIG 的 tab 切换只换色。
