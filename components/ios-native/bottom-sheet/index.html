组件要点

  • 触发按钮：实心胶囊 --ios-accent，50px 高 ≥44pt，按压 scale 回弹。
  • 纯色遮罩：rgba(20,16,10,.32) 只压暗、不模糊——整段 0 个 backdrop-filter。
  • spring 弹起：白面板 14px 14px 0 0 圆角，translateY(110%) → 0 走 --ios-spring；遮罩淡入走 --ios-damped。
  • 结构：36×5 grabber + 20/700 标题 + 13pt 副标题 + 3 行 srow（.5px 发丝线分隔）+ tinted「打开章节」。
  • 整层可拖：面板任意处按住下滑跟手位移（日志滚动区内除外，区内滚动优先），拖动超 6px 进入拖拽态，松手超过面板 35% 或快速甩动即关闭，未过线 spring 回弹归位（pointer 事件 + setPointerCapture，拖拽态吞 click 防误触）。

动手点

  • 点「继续阅读」：面板从底部弹起、遮罩同步淡入。
  • 点遮罩任意处 / 「打开章节」：两者都能关闭。
  • 面板内点「加入今晚读完」的开关占位（内联最小 markup）。

刻意没做

  • 遮罩不模糊——不是毛玻璃 sheet，纯色压暗就够。
  • 面板不带玻璃质感、不做拖拽手势（demo 只留点按关闭）。
  • 无 stock 蓝：主按钮赤陶实心、次按钮赤陶 tinted。
