组件要点

  • 40pt 轨道：--ios-track（6% 墨色）圆角 10、内衬 2px；白 thumb 带轻投影在轨内滑动。
  • 两条动效语义：位移走 --ios-spring（轻微回弹），文字色变化走 --ios-damped（临界阻尼不回弹）。
  • 选中 15/600 ink、未选 ink2：只靠字色分主次，不加下划线、不加描边。
  • thumb 位移：translateX(calc(N*(100% + 1.6px)))，段数变化只需改 thumb 宽度。

动手点

  • 点三个分段：thumb 轻回弹滑动，文字色同步阻尼过渡。
  • 连续快速点击：transition 只认最终值，不会叠成抖动。

刻意没做

  • 无 stock 蓝选中态、无下划线指示条——iOS 分段就是白块滑动。
  • 无 backdrop-filter、无毛玻璃轨道。
  • 轨道不加高对比描边：--ios-track 6% 墨色足够。
