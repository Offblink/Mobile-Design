组件要点

  • 两层纪律：Tab 条是控件层，下面的照片与白卡全部不透明——玻璃的模糊/饱和来自背后内容。
  • 最小化行为：向下滚过 140px 收缩至 54px、标签折叠；回滚或近顶（<80px）立即展开。尺寸/圆角走 --spring（spatial 回弹），透明度/颜色走 --damped（绝不回弹）。
  • active 反馈：图标 scale(1.12) + 色彩加深（--ios-ink2 → --ios-ink），其余保持单色。
  • 胶囊比例：高度 74 → 54 时圆角 32 → 27 同步跟随，外形不走样。
  • 留边：left/right 12、bottom 14，玻璃与机身边缘保持呼吸，不贴边。

动手点

  • 向下滚 → Tab 条最小化；往回滚 → 弹性展开（弹簧回弹一次）。
  • 点 4 个 tab → 切换 active（缩放 + 加深 + 保留 label）。
  • 滚到第二张彩色照片 → 看玻璃颜色如何被背后内容改变。

刻意没做

  • 玻璃不上内容层、不给每个图标上色、标签不用 ALL-CAPS、不做彩色角标点缀。
