组件要点

  • 两条 keyframes 叠加：morph 2.4s ease-in-out 改 border-radius 四角百分比；spin 3.6s linear 转 360°——形变不同步于自转，读起来是「活的」。
  • 渐变填充：primary→tertiary 对角渐变，形变时色随形走。
  • 尺寸档位：同一段动画适配 56 / 34 / 20px 三档，blob 用 flex:none 不被挤压。
  • 配套 loader 行文案：主句 600 字重 + 副句说明组件身份。

动手点

  • 盯住四角：border-radius 在两组八值之间来回插值，圆与尖角持续轮换。
  • 对比两档：动画时长不随尺寸改变，节奏一致。

刻意没做

  • 不做圆形 spinner、不做匀速旋转的 SVG 进度环、不给形变加固定时长 tween。
