连接式分段按钮（button-group）

M3 ButtonGroup（connected）：一条 outline-variant 胶囊外框把三个选项连成整体，选中项铺 secondary-container 底——替代 SegmentedButton 的圆角分段。demo 把它放进一张「统计周期」卡里，切换时下方数值跟着换。

组件要点

  • 一条外框：容器 border: 1px solid --m3-outline-variant + border-radius: 999px + overflow:hidden，三个按钮共享一枚胶囊。
  • 竖分隔线：button + button 用 border-left 画出，外框由容器统一兜住，不会双线。
  • 选中态：secondary-container 底 + on-secondary-container 文字，颜色过渡走 --damped。
  • hover：未选项 hover 铺 --m3-sc 底——M3 state layer 的容器级表达。

动手点

  • 切 本周 / 本月 / 年度，看选中底色滑过去、下方数值同步换。
  • 在未选项上悬停，观察只出现一层 sc 底色。

刻意没做

  • 不做 SegmentedButton 的独立圆角分段、不给分段各自描边、不用 primary 一色到底。
