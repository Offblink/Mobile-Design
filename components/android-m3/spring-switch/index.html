双弹簧开关（spring-switch）

M3 开关：knob 位移与放大走 spatial spring（约 10% 回弹），轨道颜色走 effects spring（临界阻尼、绝不回弹）——同一控件里两种弹簧语义并存。demo 展示三行设置项，可逐个点开关观察差异。

组件要点

  • knob = spatial spring：transform/width/height 用 --spring（cubic-bezier(.34,1.56,.64,1)），位移 20px、尺寸 24→28px，到位时约 10% 回弹。
  • 轨道色 = effects spring：background/border-color 用 --damped（临界阻尼），颜色绝不回弹——一控件双弹簧语义。
  • 勾选图标显隐走 opacity var(--damped)，颜色类过渡同样不回弹。
  • 尺寸变化让 knob 在轨道两端自然贴边（M3 state layer 之外的 shape-change）。

动手点

  • 逐个点开关，盯 knob 的回弹与轨道的直落——同一帧两种曲线。
  • 连点几个开关，感受 spatial spring 的「甩」与 damped 的「稳」对比。

刻意没做

  • 没有单一曲线打天下（颜色不做回弹）、没有 tween 时长动画、没有 48dp 前的圆形 knob 贴边。
