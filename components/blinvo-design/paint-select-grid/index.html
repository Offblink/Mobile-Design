涂抹多选 · 相册网格（paint-select-grid）

二维网格上的涂抹多选：长按任意照片进选择模式，此后按住拖动 = 范围选择。关键在于语义不跟几何走——起笔那格是锚点，锚点到笔尖所在格之间的整段按本笔方向翻转，所以斜着从左上拖到右下 = 起点到终点全选，不管手指实际压没压到中间那些格子。起笔落在已选图上 = 这笔取消；收笔后甩出区间的自动撤销。

组件要点

  • 语义 ≠ 几何：网格只是排布，选择按一维照片序列走——锚点 anchorIdx ↔ 笔尖 curIdx 的整段 [min,max] 落选中/取消，斜拖跨行也照样「起点到终点全选」。
  • 起笔定方向：第一笔 paintAt 时才决定 dir（锚点已在选 = 这笔取消），整笔不翻转——回拖只靠区间裁决。
  • 甩出区间自动撤销：本笔碰过的格子记在 strokeApplied 里；回拖后不在 [lo,hi] 内的就地回滚。只碰本笔动过的，之前就选好的天然不受影响。
  • 起涂门槛：位移 > touchSlop 才算涂抹（Android ViewConfiguration.getScaledTouchSlop()），并掐掉挂起的长按、禁止滚动抢手势。
  • 选中态只改叠层：压暗 30% + 内嵌 2px 描边（Prism select_overlay），不重排不重绘缩略图。

动手点

  • 长按（按住约半秒）任意一格 → 进选择模式并勾住它。
  • 选择模式里按住拖动：从第 1 格斜着拖到第 8 格 → 中间整段全选，包括手指没压过的格子。
  • 选中一整段后往回拖 → 甩出区间的自己撤销；试着来回甩，看区间怎么裁决。
  • 起笔落在已选图上再拖 = 这笔整段取消（方向由起笔那格决定）。
  • 顶栏「选择」也能进模式（长按是 Prism 原生入口，这里补一个便于发现）；「取消」退出并清空。

刻意没做

  • 不做中途换向（列表那版在拐点翻方向、新段从拐点起算；这版锚点固定、整笔方向不翻）、不做贴边自动滚动（列表那版有 56px 带 / 14px 每 30ms 那套）、不做橡皮擦与套索、不做选中时整格重排。
