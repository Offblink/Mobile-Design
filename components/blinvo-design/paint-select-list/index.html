涂抹多选 · 列表（paint-select-list）

一维列表上的涂抹多选，入口是长按卡片（500ms，越过 10px 就作废——那是滚动不是长按）：进模式后左边现出圆形单选框，从单选框起笔拖动 = 选中「段起点 → 笔尖所在卡」之间全部。跟相册网格那版的差别在折返——中途换向会翻转方向、把新段起点挪到拐点；另有贴边自动滚动，笔尖靠近上/下缘列表自己滚起来，越贴越快，滚过的行继续跟着涂。

组件要点

  • 入口只有长按：HOLD_MS = 500 起手，位移超过 SLOP = 10px 立即作废（那是滚动不是长按）。长按那笔的收尾 click 由 held 标志吃掉，否则刚勾上的又被翻回去。
  • 模式换 chrome：顶栏标题变「已选 N 项」、右侧筛选让位给「取消」、批量底栏浮出；左侧 ‹ 与取消走同一条出口。
  • 起笔只认单选框：.ck 平时 display:none，进模式才现身（模式门槛由显示本身管）；它带 touch-action:none，卡片其余区域的拖动仍留给滚动。
  • 段区间重放：paintRange(to) 把 [min(seg,to), max(seg,to)] 全设成本笔方向，幂等（setRowSel 状态没变就返回），来回甩不会翻来翻去。
  • 折返换段：新落点行号方向 d 与上一步 dx 相反 → 方向翻转 + seg = 拐点，新段从拐点起算。dx 初值 0，所以首步永不误判成折返。
  • 贴边自动滚动：EDGE = 90 的滚动带，requestAnimationFrame 每帧走 3 → 16px（越贴边越快）；笔尖不动也滚——靠 lastPt 持续 rowUnder 取行接着涂；出带、到顶/到底立刻停。
  • 收笔吞 click：suppressClick 吃掉涂抹收笔与长按收尾那两次 click；没动的轻点就地翻选这一格。收尾挂 window 上，指针划出列表也不会留下悬挂的定时器。

动手点

  • 长按任意一张卡片约半秒 → 进多选并勾住它（快速划动 = 滚动，不会误入）。
  • 从任一圆形单选框按住往下拖 → 段起点到笔尖之间整段选中。
  • 选中一段后往回拖 → 在拐点折返：方向翻转，新段从拐点起算。
  • 按住贴到列表上缘或下缘 → 列表自己滚起来，越贴越快，滚出来的卡继续跟着入选；手指不用来回挪就能选完一整屏。
  • 抬手前没动 = 就地翻选这一格；多选模式里点卡片任意位置也翻选。

刻意没做

  • 不做「批量选择」按钮（入口只有长按）、不做固定锚点的整笔区间（那是相册网格版的裁决方式）、不做套索与橡皮擦、选中只改这一格的 .on 不整列表重绘（滚动位置不能丢）。
